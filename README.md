# 口播短视频AI自动化剪辑

这套 Codex Skill 用于整理真人口播和访谈，并按已确认的阶段完成剪辑。两个文件夹一起安装。

| 文件夹 | 用途 |
| --- | --- |
| `ai-talking-head-video-editing` | 从选题、文稿、原声试听走到粗剪、字幕、标题、包装和剪映交付 |
| `recorded-talking-head-editor` | 转写整理、说话人核对、原声排稿和逐句修改记录 |

## 安装

1. 在 GitHub 仓库页选择 **Code → Download ZIP**，或[直接下载 ZIP](https://github.com/ljiao0729-lang/ai-talking-head-video-editing/archive/refs/heads/main.zip)，然后解压。
2. 把里面的 `ai-talking-head-video-editing` 和 `recorded-talking-head-editor` 两个文件夹复制到 Codex 用户技能目录。macOS 和 Linux 通常是 `~/.codex/skills/`。如果设置了 `CODEX_HOME`，用该目录下的 `skills/`。
3. 确认两个文件夹各自直接包含一个 `SKILL.md`。打开一个新的 Codex 对话，发送下面的启动语。已有旧版时，先备份自己改过的规则，再替换对应文件夹。

## 开始剪第一条

> 按口播剪辑流程继续。原片在【目录】。这条要讲【选题或核心观点】。我已确认到【阶段】，请先交【这一步需要的产物】。

只有原片也可以开始。提供可访问的文件或目录，先做转写和选题归类。已有逐字稿、确认稿、试听或剪映工程时，一起提供，并说明哪份是最新版。多条视频分别标注已确认阶段。

## 每步怎么验收

1. **选题**　确认标题方向、核心观点和类别。逐字稿要有说话人、素材名和时间码。
2. **剪辑稿**　先定结构和必保原声，再用豆包排稿并回查原声。每条交成片版和原片修改版，删减理由写在原句旁。局部改稿只动指定范围，补结尾只用已核对且能接回同一观点的原话。
3. **试听与粗剪**　先听原声衔接，再按确认音轨剪画面。保留有用的提问、笑声和情绪，前后各留约 3 秒气口。工程以用户当前手调版为准。
4. **字幕与包装**　依次确认字幕、标题与人名条、配画方案和独立素材。即梦视频通常 8–10 秒，动态图解通常 6–8 秒。确认素材后再上轨。
5. **工程交付**　在时间线上实际播放，核对原声、字幕、入出点和片尾。先交可编辑工程，需要正式成片时再导出。

## 工具准备

自动转写需要可用的转写工具，也可以直接提供带时间码的逐字稿。豆包、即梦 Seedance 和剪映用安装者自己的账号和环境。工具不可用时，流程会交付已能完成的文稿、分镜或带时间码的剪辑清单，并标明完成阶段。
