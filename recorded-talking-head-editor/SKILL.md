# 已录口播选题与文稿梳理

## 1. 同步素材与转写

读取目标范围内的已有同传逐字稿。只有音视频时，先转写。按原素材和录制顺序保留原话、文件夹、文件名、片内时间码和说话人。区分主持人、嘉宾和设备等其他声音，特别核对第一人称经历和引述。文字判断不清时回听，仍不确定就标「说话人待核」，暂不归到个人名下。时间码未经原声复核时注明来源。缺少可靠时间码时用段号和原句定位。整理稿另存，原始音视频和逐字稿作为核对依据。

## 2. 先交选题归类，确认后再写稿

按主目标把选题分为流量型（受众痛点、反差或实用观点）、业务型（产品、服务或案例）、个人型（人物经历、判断或选择）。每题标「提纲内」或「新选题」，附素材、时间码和实录状态。提纲用于对照，按实拍内容增删和调整。属于已有题目的论据并入该题。现场新题须有足够原声或可独立展示的场景，注明素材缺口。产品演示标「产品展示型」，办公环境等轻 Vlog 用画面和走访路线串联。

先提交归类表。选题和方向经用户确认后，再进入结构判断、必保原声标记和豆包排稿。已经明确确认的方向直接进入下一步。

## 3. 先定内容结构和必保原声，再用豆包排稿

先用一句话明确观众看完能得到什么。流量型、业务型、个人型用于归类；根据素材用观点、干货步骤或人设故事结构剪同一条成片。

- **观点型**：最有冲击力且能独立听懂的观点尽早出现，紧接最能解释或证明它的原声论据。「为什么」类选题优先给出原因。
- **干货型**：原声有例子或事实时尽早给出，再按录制中实际讲到的「首先、然后」等顺序展开。保留每一步的名称、必要解释和条件。分点编号可作编辑标记。能独立回答另一问题的素材列入候选选题。
- **人设故事型**：保留支撑观点的经历、关键行动和结果，以及使结论成立的前后对照。保留笑声、语气或音量变化和触发它们的原话。

**金句开头的人物观点稿**：把有情绪、能独立听懂的嘉宾原句放在开头。若这句只呈现感受，紧接一句嘉宾对自己的明确判断，再把解释判断的经历、前后变化或具体做法放在中段。结尾保留原声里能把意思讲完的感慨或总结。

排稿前向前后查找缺失的论点和论据。用户要求嘉宾独白时，用嘉宾自己的原话交代主题。保留承载观点的关键词、情绪性重复和完整论据，按内容决定时长。交稿前只读成片正文，检查能否听懂“开头为什么这样说、嘉宾怎么看、哪段原话能说明”。有一项说不清，就回原片补原句再排。

先标出必保的观点、论据、步骤、故事、情绪和必要上下文，附说话人、素材名和时间码。把结构和必保标注连同逐字稿交给豆包。删减后核对下一句的指代、因果和故事衔接。拿不准的精华句先保留，在原句旁标「可选删」及取舍。

通过可用的豆包模型或已登录的豆包端提交该题所需的逐字稿、说话人、时间码和剪辑约束。逐句核对豆包返回的内容与原话、说话人和切点，检查拼接后句意和上下文。豆包不可用时如实说明，保留已确认的题单，并继续本地核对原声和素材出处。

每题交一份成片。短平快按核心观点、论据、互动组织。通用引流按痛点、解决方案或干货、互动组织。深度人设从原声观点或金句进入，用本人经历和论据讲清底层认知。根据素材选用结构。需要主持人交代问题时，可把原声提问放在开头，再接嘉宾观点和论据。嘉宾回答能独立讲清楚，或用户指定只留嘉宾时，保留连贯的嘉宾回答。互动可用录到的原话，也可作为评论区或画面包装提示，后者单独标注。

原声只允许删减、调序和重组。保留原词、句意、限定条件、说话人及必要上下文。检查观众能否听懂开场在讲什么、后文的指代以及观点与论据的关系。删去口水词、重复、口误、失败起句和无表达作用的停顿。保留现场笑声、语气变化、情绪反应和自然气口，连同引发该反应的上下文一起处理，切点存疑就复听。

按内容密度和完整性定时长，净口播通常在约 3 分钟以内。论据、方法或故事有足够价值时可以做长；只有一段精彩且能独立听懂时可以做短。扣除口误、重说、无效停顿和片头片尾剪辑余量后核算净时长，气口余量单列。

需要视频号标题时，用豆包基于成片给 5 个候选，覆盖痛点暴击、认知反差、金句观点和互动提问，第五个按题目选角度。主标题一般两行，合计 15–20 字，空格和标点不计，AI 按两个字符计。默认省略第三行小字。用观众关心的问法，并核对标题与成片一致。标题如需随单条交付，放在成片版下作为封面建议，明确与口播正文的边界。

### 局部改稿与补结尾

以用户最后确认的稿件为底稿。先确定指定修改范围，只在范围内删减、调序或补入原话。其他段落的措辞和顺序逐字沿用。若需要移动范围外的句子才能让逻辑成立，先给局部可行稿，并把跨段调整留作单独建议。

补结尾时，先说清上一句在讲什么，以及这条需要收束的核心观点。候选原话必须能直接承接上一句，并补足同一观点的论据、结果或总结。仅仅题材相近、出现同一关键词或能延长时长，都不足以入选。对每句复听实际音频，核对说话人、原词和源时间码，并连读确认指代和语义。用户指定嘉宾独白时，只选该嘉宾的话。只有逐字稿或说话人无法确认时，标作待核候选。找不到符合条件的原声时，保留确认稿的结尾并说明。

## 4. 单条只交两部分

1. **成片版**。按实际播放顺序给出可连贯阅读的完整原声文本。文件名、时间码和预计净时长放在正文旁或之后，便于按稿粗剪。交付前通读全文并逐段核对出处。
2. **原片修改版**。按录制顺序完整呈现该题对应的原话与时间码。建议删掉的字句用删除线，紧接括号写具体理由。保留的原话正常显示。调序时原句留在原位，括注去向和理由。跨素材注明两边的文件及时间码。情绪和动作可在相邻位置标注，存疑时标待复听。省去录制间隔时标出范围，方便人工复选。

## 按需导出原声试听

用户确认文本并要求试听后，用对应原片剪原声。片头、片尾各留约 3 秒剪辑余量。片尾留量从最后一句、动作和情绪自然结束后起算。源素材不足时可补静音并注明。分别核对净口播与含前后余量的试听总长。
